# 08. Отчёт: заполнить по ходу работы — около 4 минут

[← Оглавление](../README.md) · [← Проверка](07-check.md) · [Далее: Объяснения →](09-learn.md)

По КИМ отчёт нужен **по ходу настройки**, со схемами/таблицами и результатами. Итоговое имя файла: **`ФамилияУчастникаЗадание1`** (например, `ИвановЗадание1.docx`). Формулировки ниже можно использовать как **основу**, но не выдавай непроверенные результаты за выполненные.

## Шаблон текста отчёта

```text
Задание 1. Проектирование и настройка сетевой инфраструктуры
Участник: ______________________

1. Имена устройств и IPv4
   Настроены полные доменные имена устройств и адреса по таблице 2.
   Доказательство: вывод hostname/ip -br a/show ip interface brief.

2. ISP и Интернет
   Настроен WAN по DHCP, соединения с HQ/BR и динамический NAT.
   Доказательство: ip route, iptables -t nat -S, ping внешнего адреса.

3. Учётные записи
   sshuser на HQ-SRV/BR-SRV: UID 2027; sudo без пароля.
   net_admin на HQ-RTR/BR-RTR: права администратора.
   Доказательство: id -u sshuser; sudo -l -U sshuser; конфиг роутера.

4. Коммутация VLAN
   VLAN 100 — HQ-SRV; VLAN 200 — HQ-CLI; VLAN 999 — управление.
   Маршрутизация VLAN осуществляется HQ-RTR через один порт te1.
   Доказательство: настройка service-instance, VLAN Tag в Proxmox.

5. SSH
   Порт 2027, только sshuser, MaxAuthTries=2, баннер.
   Доказательство: конфигурация sshd и успешное подключение.

6. GRE
   HQ-RTR 10.10.10.1/30 ↔ BR-RTR 10.10.10.2/30.
   Доказательство: ping по туннелю и конфигурация интерфейсов.

7. OSPF
   Настроен OSPF для маршрутизации офисов, аутентификация MD5
   на GRE с ключом из задания, OSPF-соседство BR-FW с BR-RTR.
   Доказательство: show ip ospf neighbor; vtysh; маршруты.

8. NAT офисов
   На HQ-RTR и BR-RTR настроена динамическая трансляция.
   Доказательство: show ip nat translations, выход в интернет.

9. DHCP
   HQ-RTR выдаёт HQ-CLI IPv4, маску, шлюз, DNS и суффикс домена.
   Доказательство: ip -br a; ip route; /etc/resolv.conf на HQ-CLI.

10. DNS
   HQ-SRV обслуживает au-team.irpo; A/PTR по таблице 3;
   внешние запросы пересылает на публичные DNS.
   Доказательство: host -t A ..., host IP_АДРЕС ..., host ya.ru ...

11. Часовой пояс
   На устройствах установлен пояс места проведения экзамена.
   Доказательство: timedatectl / конфигурация EcoRouter.
```

## Самые полезные скриншоты

- ISP — IPv4 + маршрут, NAT;
- HQ-RTR — интерфейсы, VLAN, OSPF, NAT, DHCP;
- BR-RTR — GRE, OSPF;
- BR-FW — `vtysh -c 'show ip ospf neighbor'`;
- HQ-SRV — записи DNS A/PTR, порт 53, SSH 2027;
- HQ-CLI — DHCP, шлюз, DNS;
- BR-SRV — `id -u sshuser`, доступность HQ-SRV.

**Не перегружай отчёт скриншотами пустой консоли.** Один чёткий снимок с несколькими проверками лучше, чем десять плохо читаемых.
