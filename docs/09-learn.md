# 09. Что нужно понимать для защиты — короткий словарь

[← Оглавление](../README.md) · [← Отчёт](08-report.md)

## Что означает каждая технология

| Термин | Как объяснить преподавателю простыми словами |
|---|---|
| IPv4 | Адрес устройства в сети, например `192.168.0.2` |
| Префикс `/27` | Размер подсети: 32 адреса, 30 обычных адресов устройств |
| Default gateway | Маршрутизатор, которому отправляют пакеты в другие сети |
| VLAN | Логическое разделение одной физической сети по тегам |
| Access VLAN | Устройство получает обычные кадры, коммутатор сам назначает VLAN |
| Trunk / 802.1Q | По одному физическому порту передаются кадры разных VLAN с тегами |
| DHCP | Автоматическая выдача IP, шлюза, DNS и доменного суффикса |
| DNS | По имени узнаёт IP (A), по IP узнаёт имя (PTR) |
| dnsmasq | DNS-сервер HQ-SRV, умеет отдавать локальные имена и пересылать внешние запросы |
| NAT overload | Несколько внутренних устройств получают выход наружу через один внешний IP и разные порты |
| GRE | IP-туннель между HQ-RTR и BR-RTR |
| OSPF | Протокол, через который маршрутизаторы узнают чужие сети автоматически |
| MD5 в OSPF | Хешированный механизм аутентификации по условиям учебного задания |
| FRRouting | Программный маршрутизатор для Linux, на BR-FW использует OSPF |
| `ip_forward=1` | Разрешает Linux пересылать пакеты между интерфейсами |
| SSH | Защищённый удалённый доступ к консоли, в задании порт 2027 |
| `AllowUsers` | Ограничивает, каким пользователям разрешено подключаться по SSH |
| sudo | Разрешает выполнять выбранные действия с правами администратора |
| etcnet | Система постоянной настройки сети ALT Linux через `/etc/net/ifaces` |
| `systemctl` | Управление службами: запуск, перезапуск, автозапуск |
| `iptables` | Правила фильтрации и NAT в Linux |

## Разбор типовых команд

```bash
ip -br a                         # краткая таблица интерфейсов и адресов
ip route                          # где расположены шлюзы и маршруты
ping -c 2 192.168.0.1             # отвечает ли ближайший шлюз
host ya.ru 192.168.0.2            # DNS-запрос именно к HQ-SRV
ss -tulnp | grep ':53'            # кто слушает TCP/UDP порт 53
ss -tlnp | grep ':2027'           # кто слушает SSH 2027
systemctl restart network         # применить etcnet (может прервать связь)
systemctl restart dnsmasq         # перезапустить DNS
sysctl net.ipv4.ip_forward        # включена ли IP-пересылка
iptables -t nat -S                # правила NAT на Linux
```

```text
show port brief                   ! физические порты EcoRouter
show ip interface brief           ! адреса EcoRouter
show ip route                     ! маршруты EcoRouter
show ip ospf neighbor             ! OSPF-соседи
show ip nat translations          ! текущие NAT-трансляции
write memory                      ! сохранить конфигурацию после перезагрузки
```

## Вопросы, которые легко зададут

**Почему HQ-CLI и HQ-SRV разные VLAN?** — Чтобы разделить сети клиентов и серверов, но разрешить маршрутизацию через HQ-RTR.

**Почему HQ-SRV `/27`, а HQ-CLI `/28`?** — По заданию сети должны вмещать соответственно не более 32 и 16 адресов. `/27` — 32 адреса, `/28` — 16.

**Почему BR-FW ↔ BR-RTR `/30`?** — На point-to-point соединении нужны два рабочих IP; `/30` даёт два адреса устройств.

**Зачем OSPF, если есть default route?** — Default route ведёт на провайдера, OSPF сообщает конкретные маршруты внутренних сетей обоих офисов.

**Почему GRE не шифрует?** — GRE инкапсулирует пакеты, но сам по себе не обеспечивает конфиденциальность. MD5 в OSPF защищает механизм аутентификации маршрутизаторов, **не шифрует трафик GRE**.

**Зачем DNS на HQ-SRV, если интернет и так открывается по 8.8.8.8?** — Внутренние имена `*.au-team.irpo` должны определяться через собственный DNS; внешний DNS их не знает.

**Почему `host ... 192.168.0.2` работал только на сервере?** — Раньше `dnsmasq` слушал только `127.0.0.1`. После разрешения прослушивания на `192.168.0.2` клиент смог обращаться к DNS по сети.

**Почему не использовали VLAN-интерфейсы в гостевой ОС?** — Потому что Proxmox уже назначает теги 100/200 виртуальным портам; для ALT Linux это обычный Ethernet.

**Что делает `MaxAuthTries 2`?** — Ограничивает число попыток аутентификации в рамках одного SSH-соединения; это не глобальная блокировка аккаунта на две попытки.

**Зачем `write memory`?** — Чтобы конфигурация EcoRouter сохранилась после перезагрузки.

## Главное правило диагностики

Проверяй последовательно: **IP → ближайший шлюз → маршрут → внешний IP → DNS → конкретная служба**. Не исправляй DNS, если даже ближайший шлюз не отвечает.
