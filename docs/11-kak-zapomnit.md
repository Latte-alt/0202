# 11. Как запомнить команды, а не просто копировать

[← Оглавление](../README.md) · [Начать с ISP](01-isp.md) · [Шпаргалка](10-cheatsheet.md)

> **Режим обучения.** Цель — самому набрать первое задание за час, а не зазубрить огромный скрипт. Не вводи команды, значение которых не понимаешь. Большие файлы проще открывать в `mcedit`, чем запоминать экранирование, кавычки и `sed`.

## 1. Пять базовых команд ALT Linux

| Команда | Запомнить как |
|---|---|
| `cd КАТАЛОГ` | «перейти в папку» |
| `mcedit ФАЙЛ` | «открыть файл и написать обычный текст» |
| `echo ТЕКСТ > ФАЙЛ` | «записать одну строку» (перезапись!) |
| `cp ИСТОЧНИК КОПИЯ` | «сделать копию» |
| `systemctl restart СЛУЖБА` | «перезапустить службу» |

В `mcedit` обычно: **F2 — сохранить**, **F10 — выйти**.

Мнемоника: **зашёл → отредактировал → указал адрес → перезапустил → проверил**.

## 2. Один шаблон настройки IP для всех серверов

На сервере с интерфейсом `ens18`:

```bash
cd /etc/net/ifaces/ens18
mcedit options
echo 192.168.0.2/27 > ipv4address
echo 'default via 192.168.0.1' > ipv4route
systemctl restart network
ip -br a
ip route
```

В файл `options` вписывай **обычные строки**, а не длинную команду:

```ini
TYPE=eth
BOOTPROTO=static
NM_CONTROLLED=no
DISABLED=no
CONFIG_IPV4=yes
ONBOOT=yes
```

Повторяющиеся настройки запоминай **один раз**. На BR-SRV меняются только последние цифры IP и шлюза: `192.168.4.2/28` и `192.168.4.1`.

Если каталога нет, перед `cd` — `mkdir -p /etc/net/ifaces/ens18`. Если сетью управляет NetworkManager, сначала переводим интерфейс на etcnet: два менеджера одновременно не использовать. Перезапускать сеть из консоли Proxmox, не по SSH.

Для HQ-CLI в `options` нужна **только одна замена** — `BOOTPROTO=dhcp`. Тогда `ipv4address` и `ipv4route` не задаются.

## 3. Семь команд, которые нужно уметь объяснить

```bash
hostnamectl set-hostname ИМЯ
ip -br a
ip route
ping 192.168.0.1
apt-get install ИМЯ_ПАКЕТА
systemctl restart ИМЯ_СЛУЖБЫ
timedatectl set-timezone Asia/Yekaterinburg
```

Помни смысл, а не порядок букв:
- `ip` — узнать адрес и маршрут;
- `ping` — проверить связь;
- `apt-get` — поставить службу;
- `systemctl` — запустить;
- `timedatectl` — настроить время.

## 4. Как запомнить EcoRouter

**Везде одна последовательность:**

```text
enable
configure terminal
...настройки...
end
write memory
```

**Адрес интерфейса:**

```text
interface ИМЯ
 ip address АДРЕС/МАСКА
exit
```

**Привязка физического порта (EcoRouter, а не Linux):**

```text
port te0
 service-instance te0/isp
  encapsulation untagged
  connect ip interface isp
 exit
exit
```

Эту форму вводишь **дважды** для WAN двух роутеров, изменяя только IP в `interface isp`. Для VLAN меняются `te1`, `dot1q 100` и `vl100` — принцип тот же.

**Маршрут по умолчанию:**

```text
ip route 0.0.0.0/0 АДРЕС_ПРОВАЙДЕРА
```

**Туннель GRE:**

```text
interface tunnel.0
 ip address 10.10.10.1/30
 ip mtu 1400
 ip tunnel 172.16.1.2 172.16.2.2 mode gre
exit
```

На BR меняются местами исходный/конечный WAN и адрес GRE становится `10.10.10.2/30`.

**OSPF:** запоминай связку `router ospf 1` → `router-id` → `passive-interface default` → `no passive-interface tunnel.0` → `network ... area 0`. Для BR-RTR дополнительно `no passive-interface fw`, иначе не появится соседство с BR-FW.

**NAT и DHCP:** у EcoRouter есть длинные команды, которые нельзя безопасно заменить произвольными сокращениями. Они расписаны **по смысловым блокам** в [разделе маршрутизаторов](02-routers.md). Выучи сначала порядок и изменяемые числа, затем набирай блок без подсказки.

## 5. Числа, которые проще запомнить парами

```text
Сторона HQ:     ISP 172.16.1.1  →  RTR 172.16.1.2
Сторона BR:     ISP 172.16.2.1  →  RTR 172.16.2.2
VLAN 100:       шлюз 192.168.0.1 → сервер 192.168.0.2
VLAN 200:       шлюз 192.168.1.1 → клиент DHCP
BR-RTR—BR-FW:   192.168.3.1      → 192.168.3.2
BR-FW—BR-SRV:   192.168.4.1      → 192.168.4.2
GRE:            10.10.10.1      → 10.10.10.2
```

Правило: **`.1` — чаще шлюз, `.2` — сосед** в этом конкретном плане, кроме DHCP.

## 6. Как тренироваться перед экзаменом

**Первый проход.** Настрой одну машину, глядя в полную инструкцию. Не копируй всю страницу — печатай команды сам и объясняй каждую.

**Второй проход.** Открой только [шпаргалку](10-cheatsheet.md). Пытайся восстановить настройки из памяти, подсматривая лишь там, где забыл.

**Третий проход.** С нуля выполни задание на копии стенда с таймером. Записывай команды, которые забываешь, и повторяй именно их. **Засчитывай шаг только после проверки**: IP, шлюз, нужная служба.

## 7. Что НЕ учить наизусть

- `sed -i` с регулярными выражениями;
- `printf '%s\\n'` и длинные конструкции `cat <<EOF`;
- `awk`/циклы Bash/однострочные скрипты;
- сложные команды автоматического поиска интерфейсов.

Это инструменты автоматизации, а **не обязательные команды для ручной сдачи**. На экзамене проще открыть файл в редакторе, записать понятные строки и проверить результат.

## 8. Минимум на каждый этап

1. **ISP:** три IP, forwarding, NAT, пинг.
2. **HQ-RTR:** VLAN/шлюзы, GRE, OSPF, NAT, DHCP.
3. **BR-RTR:** два IP, GRE, OSPF, NAT.
4. **HQ-SRV:** IP, sshuser, SSH, DNS.
5. **BR-FW:** два IP, forwarding, FRR OSPF.
6. **BR-SRV:** IP, sshuser, SSH.
7. **HQ-CLI:** DHCP, DNS.
8. **Все:** часовой пояс и короткая проверка.

**Безопасная оптимизация:** одна настройка службы → одна проверка. Не трать экзаменационное время на Samba, RAID, NFS и Docker: это второе задание.
