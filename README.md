## ⭐ Сначала изучи [как запомнить команды](docs/11-kak-zapomnit.md)

**Это основной режим подготовки.** На экзамене ты должен сам печатать команды. Поэтому длинные однострочники и регулярные выражения в тексте заменены на простое редактирование файлов через `mcedit`. Сложные синтаксические блоки EcoRouter приходится учить по частям — они предусмотрены самим оборудованием.

## 🚀 Самый быстрый порядок

1. Уточнить сетевые карты и VLAN в Proxmox, записать имена интерфейсов.
2. Настроить **ISP** и проверить интернет.
3. Ввести полный конфиг **HQ-RTR**, затем **BR-RTR** (один `write memory` на роутер).
4. Настроить **HQ-SRV** (включая DNS), затем **BR-FW** (FRR), затем **BR-SRV**.
5. Настроить **HQ-CLI** через DHCP. Выполнить сквозные проверки.
6. Снять нужные выводы в отчёт сразу после проверки, не в конце «по памяти».

**Не запускай автоматический `demo.sh` при работе по этому руководству:** он может изменить уже работающие настройки, в частности `ens18` и DNS. Здесь действия выполняются вручную, по отдельным блокам.

### Особенности именно этого стенда

- Proxmox в сети колледжа `192.168.100.0/24`, поэтому внутренние лабораторные подсети не пересекаются с ней.
- HQ-SRV получает **VLAN Tag 100**, HQ-CLI — **Tag 200** в Proxmox; отдельные VLAN-интерфейсы в Linux **не создаются**. HQ-RTR должен получать **tagged** трафик на порт HQ-LAN.
- На ALT Linux для `ens18` используем **etcnet**, а не одновременно etcnet и NetworkManager. Если `NM_CONTROLLED=no`, работаем с `/etc/net/ifaces/ens18/`.
- На HQ-SRV `dnsmasq` обязан слушать **`192.168.0.2:53`**, не только loopback. Не допускать ответа `127.0.1.1` для `hq-srv.au-team.irpo`.
- Важно: `192.168.1.2` для HQ-CLI — **пример первого адреса пула**, не гарантия. После DHCP проверь реальный адрес и поправь A-запись `hq-cli` при необходимости.

## ✅ Минимальный критерий сдачи

`HQ-CLI → HQ-SRV (DNS) → интернет`; `HQ-SRV ↔ BR-SRV`; OSPF-соседи видны; доступ по SSH на 2027 под `sshuser`; `net_admin` создан; нужные записи DNS A/PTR есть; отчёт сохранён с требуемым именем.

Руководство уже размещено в репозитории **Latte-alt/0202**.

## Источники и границы применимости

- **Основное задание:** «Задание 1.pdf», образец КИМ 09.02.06, страницы 36–43, в частности таблица 3 DNS, требования к GRE/OSPF/NAT/SSH.
- **Пример адресов и синтаксис EcoRouter/ALT:** [altlinuxPROsto/demo0202](https://github.com/altlinuxPROsto/demo0202), в том числе файлы `ecorouter/hq-rtr-1.txt`, `ecorouter/br-rtr-1.txt`, `demo.sh`.
- Адреса частных LAN — **наш выбранный план**, поскольку КИМ задаёт размеры подсетей, а не эти точные адреса. Имена интерфейсов `ens18/ens19/ens20` — примеры, сначала проверяй соответствие сетевым адаптерам.
- В учебном задании требуется OSPF c MD5, хотя для современных промышленных сетей MD5 и общий демонстрационный пароль не являются рекомендуемой защитой.
